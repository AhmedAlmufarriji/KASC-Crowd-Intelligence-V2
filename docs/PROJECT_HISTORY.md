# Project history and attribution

## Academic inspiration

This independently implemented project was inspired by the **Umm Al-Qura University Data Science graduation project** "Data Augmentation for Predictive Crowd Management at King Abdullah Sports City Stadium" (2025–2026), publicly represented by [BandarAlsarwani/KASC-Crowd-Management](https://github.com/BandarAlsarwani/KASC-Crowd-Management).

The academic work was completed as a team by Bandar Abdullah Alsarwani, Hamzah Khaled Sherbini, Anas Mohammed Alahmdi and Ahmed Nawaf Almufarriji, under the supervision of Dr. Mohammed Halawani.

The original repository states intellectual-property rights pertaining to the university and supervisor. That declaration applies to the original code and materials.

## V2 separation

This V2 is a **separate portfolio prototype** with newly written source code, a new seeded synthetic dataset, independent ML training, separate graph topology and new bilingual interface. It does not duplicate the original dataset, model binary files, notebook or dashboard, and does not represent a continuation of a deployment by the university, stadium, or project team.

Any reuse of materials from the original repository would require the relevant authorization. Public visibility does not waive original intellectual-property rights.

## Truthful statements

- **Yes:** This V2 runs local prediction APIs trained on explicitly synthetic events and computes Dijkstra paths over an illustrative graph.
- **Yes:** The project is inspired by a collaborative academic graduation research topic.
- **No:** The V2 model has been calibrated or validated on real KASC events.
- **No:** The topology accurately represents approved stadium access or evacuation routes.
- **No:** The university, stadium operator or original team endorses this V2.
