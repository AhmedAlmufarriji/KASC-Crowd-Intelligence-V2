# Model card — V2 synthetic event forecast

## Intended task

Two supervised estimators predict 15-minute-ahead queue wait and congestion class for synthetic event/gate/time records. They are educational reference implementations, **not field-validated models for King Abdullah Sports City**.

## Models and baseline

- **Classifier:** `RandomForestClassifier` (`n_estimators=90`, `max_depth=13`, `min_samples_leaf=3`, `class_weight=balanced_subsample`, seeded). Classes `Low`, `Medium`, `High` refer to the *future* wait. Baseline: dummy majority class.
- **Regressor:** `HistGradientBoostingRegressor` (`max_iter=100`, `max_leaf_nodes=23`, seeded). Target: future wait in minutes, clipped to [0,40] at inference. Baseline: dummy mean.
- **Preprocessing:** per-model `ColumnTransformer` with numeric median imputation; categorical imputation and one-hot encoding. Model pipelines fitted on **training events only**.

## Data split

A single seeded group-aware 24% holdout on `event_id`; entire events are allocated to one split. No target or future value is included as a feature. This improves on row-random evaluation but is still a **single split rather than repeated or time-forward event-validation**, so future research should include multiple event folds and temporal transfer testing.

## Example held-out scores

From the generated 42-event dataset and fixed seed `20261027`, on Python 3.13.5 and scikit-learn 1.8.0:

- Classification accuracy: **0.9458** (majority baseline **0.6855**).
- Macro-F1: **0.8160** (baseline **0.2711**).
- Wait-time MAE: **0.8624 minutes** (baseline **10.8559 minutes**).
- Wait-time RMSE: **1.9862 minutes** (baseline **14.8087 minutes**).

These figures are for independent *synthetic* events **generated by the same process**; they should not be interpreted as demonstrated ability to handle real crowds, other stadiums, new camera feeds or emergencies.

## Risks

- **Simulation/reality gap:** generator assumptions are not verified against actual crowds.
- **Distribution shift:** changes in event type, attendance, weather or infrastructure may break relationships learned during synthetic training.
- **Group sample size:** only 42 independently parameterized events; apparent precision is limited.
- **Decision risks:** no operational capacity constraints or certified safety routes, and no modeling of wheelchair accessibility or emergency planning.
- **Metric misuse:** accuracy alone can obscure the minority Medium class; report macro-F1 and per-class checks in future.

## Appropriate next steps

Obtain appropriately licensed and ethically processed real observational data; establish time-forward and event-grouped backtests; evaluate minority labels; add probabilistic calibration, uncertainty and out-of-distribution detection; validate predictions by venue personnel; secure APIs; and clearly prevent unqualified automation of safety-critical decisions.
