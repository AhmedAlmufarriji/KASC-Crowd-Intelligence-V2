# Security policy

This is a local research prototype. **Do not** use it for real-time operations, emergency routing, security planning, or personally identifiable information.

The API is intentionally local only (`127.0.0.1`), lacks authentication, and is not hardened for public network exposure. Do not deploy publicly without security and privacy reviews. Models are loaded from locally generated `.joblib` artifacts; never replace these with arbitrary downloaded pickle/joblib files.

Report issues privately where possible, or open a public issue containing only non-sensitive descriptions. Never include credentials, exploits, or personal data in public issues.
