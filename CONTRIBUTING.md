# Contribution guide

This repository is a personal, reproducible research prototype. Focused bug reports, reproducibility fixes, feature validation and accessibility feedback are welcome.

Run `python -m pip install -e '.[dev]'` and `python -m pytest -q` before opening a pull request. Explain changes to generator assumptions or evaluation splitting, and do not misrepresent synthetic scores as real stadium performance.

Do **not** contribute unlicensed venue maps, real ticket/user-level records, credentials, leaked data, or confidential team materials. Research changes should use synthetic or expressly authorized data. Respect attribution and university intellectual-property rights in the original academic project.
